# SIQ-Browser releases

Installers for **SIQ-Browser**, the secure exam browser for SelectIQ.

**Download (always the latest):** https://github.com/manuVrtti/siq-browser-releases/releases/latest/download/SIQ-Browser-Setup.exe

From v1.0.6, SIQ-Browser updates itself: installed copies download new versions from this page in the background and install them when the app closes. You only need to download it once.
